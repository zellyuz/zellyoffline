## O'rnatish paketi tozalandi

**Ortiqcha fayllar endi o'rnatilmaydi.**

Ilgari o'rnatish paketiga ishlab chiqish paytida qolgan log fayllari ham tushib
qolardi (`frpc.log` — tashqi ulanish jurnali). Endi paketga faqat ilovaning
o'zi kiradi: loglar, tunnel sozlamalari va litsenziya fayllari chetlab
o'tiladi.

Ilova ishlashida hech narsa o'zgarmadi — 1.0.22 dagi hamma narsa o'z holicha.
