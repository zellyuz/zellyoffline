## Tashqi ulanish (relay)

**Ilova endi doimiy tashqi domen orqali ochilishi mumkin.**

Dasturchi bo'limida yangi "Tashqi domen (relay)" sozlamasi paydo bo'ldi. Relay server, domen va tokenni kiritib yoqsangiz, kassa kompyuteri o'z domeni orqali tashqaridan ochiladi — mobil hisobotlar va filial ulanishi uchun havola har safar o'zgarmaydi.

## Mobil hisobot va API

**Mobil ilova uchun API to'liq qayta yig'ildi.**

Server ichki tuzilishi modullarga bo'lindi (buyurtma, ombor, moliya, hisobot, xodimlar, stollar, chop etish). Foydalanuvchi uchun natija — hisobotlar tezroq ochiladi, ro'yxatlar sahifalab yuklanadi va katta ma'lumotda ilova osilib qolmaydi.

Kirish huquqlari qat'iylashtirildi: ofitsiant tokeni admin bo'limlariga umuman kira olmaydi.
